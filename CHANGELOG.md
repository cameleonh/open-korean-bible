# Changelog

All notable changes to this translation will be documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).
Versioning follows [Semantic Versioning](https://semver.org/):
- **MAJOR** — translation philosophy or rule changes
- **MINOR** — new books added or substantial revision
- **PATCH** — typo fixes, minor wording corrections

## [1.0.0] - 2026-08-18

### Added
- Initial release of the Korean Modern Bible translation
- 66 books (구약 39권, 신약 27권), 31,102 verses
- Data formats: JSON (per-book), JSON (combined), CSV, SQLite
- Proper noun notation using `{{name}}` format
